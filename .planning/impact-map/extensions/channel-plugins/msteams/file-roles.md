| `extensions/msteams/openclaw.plugin.json`                                                                    | Plugin manifest for id/channel registration.                                                     | Affects channel catalog, bundled plugin invariants, and setup/docs discovery.                |
| `extensions/msteams/package.json`                                                                            | Package metadata, Teams SDK/Express dependencies, exports, install metadata.                     | Affects workspace installs, runtime dependency staging, and published plugin compatibility.  |
| `extensions/msteams/index.ts` / `setup-entry.ts`                                                             | Plugin and setup entrypoints.                                                                    | Affects loader registration, setup plugin discovery, and runtime setter wiring.              |
| `extensions/msteams/api.ts` / `runtime-api.ts`                                                               | Public/local barrels.                                                                            | Keep imports inside approved plugin SDK/local API surfaces.                                  |

| `extensions/msteams/src/channel.runtime.ts` / `src/runtime.ts` / `src/test-runtime.ts`                       | Lazy runtime boundary and runtime injection helpers.                                             | Affects dynamic import behavior, tests, and SDK boundary loading.                            |
| `extensions/msteams/src/config-schema.ts` / `src/setup-core.ts` / `src/setup-surface.ts`                     | Config schema, setup adapter, wizard, DM/group policy prompts.                                   | Affects onboarding, status, credentials, allowlists, and docs/UI sync.                       |

| `extensions/msteams/src/sdk.ts` / `src/sdk-types.ts` / `src/messenger.ts`                                    | Teams SDK adapter, auth validator, turn context, proactive messaging helpers.                    | Affects webhook handling, reply delivery, and Bot Framework compatibility.                   |
| `extensions/msteams/src/monitor.ts`                                                                          | Express/Bot Framework monitor lifecycle, allowlist resolution, handlers, shutdown.               | Affects inbound webhook route, server lifecycle, credentials, and runtime logging.           |
| `extensions/msteams/src/monitor-handler.ts`                                                                  | Registers activity handlers for messages, members, reactions, invoke/file consent, and feedback. | Affects inbound dispatch, file consent, welcome cards, and feedback workflow.                |
| `extensions/msteams/src/monitor-handler/message-handler.ts`                                                  | Core message policy/routing/attachment/poll handling.                                            | Affects DM/group gating, pairing, mention gates, history, reply dispatch, and debounce.      |
| `extensions/msteams/src/monitor-handler/inbound-media.ts`                                                    | Resolves inbound media from Teams attachments.                                                   | Affects attachment downloads and media resource safety.                                      |
| `extensions/msteams/src/inbound.ts` / `src/mentions.ts`                                                      | Conversation/message id parsing, mention stripping, timestamp/quote handling.                    | Affects session keys, thread context, and inbound message body normalization.                |
| `extensions/msteams/src/policy.ts` / `src/resolve-allowlist.ts`                                              | DM/group policy and Graph-backed user/team/channel allowlist resolution.                         | Affects sender authorization, name matching, and team/channel routing.                       |
| `extensions/msteams/src/conversation-store*.ts` / `src/storage.ts` / `src/store-fs.ts` / `src/file-lock.ts`  | Persistent/in-memory conversation and poll storage helpers.                                      | Affects proactive replies, sessions, TTL/pruning, and filesystem concurrency.                |
| `extensions/msteams/src/graph*.ts` / `src/directory-live.ts`                                                 | Microsoft Graph token, users, chats, teams/channels, uploads, and live directory lookup.         | Affects allowlist resolution, directory, media downloads, uploads, and permissions.          |
| `extensions/msteams/src/attachments/**` / `src/attachments.ts` / `src/media-helpers.ts`                      | Attachment parsing, HTML/download payloads, Graph hosted content, remote media.                  | Affects inbound media, outbound attachments, SSRF-sensitive downloads, and placeholder text. |
| `extensions/msteams/src/file-consent*.ts` / `src/pending-uploads.ts`                                         | Teams file consent cards and upload completion.                                                  | Affects large file delivery and invoke callback security.                                    |
| `extensions/msteams/src/send.ts` / `src/outbound.ts` / `src/send-context.ts`                                 | Outbound text/card/media/poll send and result mapping.                                           | Affects manual sends, replies, target syntax, Graph/proactive delivery, and card support.    |
| `extensions/msteams/src/reply-dispatcher.ts` / `src/reply-stream-controller.ts` / `src/streaming-message.ts` | Reply pipeline, typing, streaming, feedback cards, chunking.                                     | Affects auto-reply delivery, stream status, feedback loop, and retry behavior.               |
| `extensions/msteams/src/polls.ts` / `src/polls-store-memory.ts`                                              | Poll card creation, vote extraction, and poll storage.                                           | Affects poll action/tool behavior and invoke handling.                                       |
| `extensions/msteams/src/feedback-reflection*.ts`                                                             | Feedback event/reflection prompt/store.                                                          | Affects thumbs up/down handling and feedback loop persistence.                               |
| `extensions/msteams/src/errors.ts` / `src/revoked-context.ts` / `src/webhook-timeouts.ts`                    | Error classification, revoked proxy fallback, webhook timeout configuration.                     | Affects reliability and operator-facing diagnostics.                                         |
| `extensions/msteams/src/**/*.test.ts`                                                                        | Colocated Teams validation suite.                                                                | First validation layer for any Teams change before broader channel/plugin gates.             |
