# synology-chat Channel Plugin File Roles

Coverage: `deep-partial`
Freshness: 2026-05-07 repo-native structural inspection only

| File or path                                                                    | Role                                                                                                          | Impact notes                                                                                |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `extensions/synology-chat/openclaw.plugin.json`                                 | Plugin manifest for id/channel registration.                                                                  | Affects channel catalog, bundled plugin invariants, and docs/setup discovery.               |
| `extensions/synology-chat/package.json`                                         | Package metadata, install docs, runtime deps.                                                                 | Affects install-on-demand and published plugin compatibility.                               |
| `extensions/synology-chat/index.ts` / `setup-entry.ts`                          | Plugin/setup entrypoints.                                                                                     | Affects loader registration, setup discovery, and runtime setter wiring.                    |
| `extensions/synology-chat/setup-api.ts`                                         | Setup-facing API exports.                                                                                     | Affects setup integration consumers.                                                        |
| `extensions/synology-chat/src/channel.ts`                                       | Main channel adapter: config/status/security, gateway start/stop, pairing, outbound, directory, prompt hints. | Central impact point for Synology behavior.                                                 |
| `extensions/synology-chat/src/accounts.ts`                                      | Hybrid account resolution and account list/default handling.                                                  | Affects setup, status, route registration, outbound, and security warnings.                 |
| `extensions/synology-chat/src/config-schema.ts` / `src/types.ts`                | Zod schema and typed account/webhook payload contracts.                                                       | Affects config validation, passthrough compatibility, and inbound payload typing.           |
| `extensions/synology-chat/src/setup-surface.ts`                                 | Setup adapter/wizard, token/incoming URL/webhook path prompts, allowlist parsing.                             | Affects onboarding, env token support, multiple accounts, allowed user IDs, and docs hints. |
| `extensions/synology-chat/src/runtime.ts`                                       | Runtime injection getter/setter.                                                                              | Affects tests and gateway/client runtime access.                                            |
| `extensions/synology-chat/src/gateway-runtime.ts`                               | Webhook route registration, routing warnings, account startup validation.                                     | Affects gateway route exposure, inherited webhook path safety, and startup blockers.        |
| `extensions/synology-chat/src/webhook-handler.ts`                               | HTTP request parsing, token auth, allowlist enforcement, trigger stripping, delivery, reply behavior.         | Main inbound security and behavior boundary.                                                |
| `extensions/synology-chat/src/inbound-context.ts`                               | Builds inbound sender/chat context.                                                                           | Affects routing context and sender identity.                                                |
| `extensions/synology-chat/src/inbound-turn.ts`                                  | Dispatches inbound turn through runtime route/agent and sends reply.                                          | Affects session keys, route updates, and reply delivery.                                    |
| `extensions/synology-chat/src/session-key.ts`                                   | Synology inbound session key derivation.                                                                      | Affects conversation/session continuity and identity links.                                 |
| `extensions/synology-chat/src/client.ts`                                        | Sends text/file URLs to incoming webhook and resolves legacy webhook names to Chat user IDs.                  | Affects outbound replies, media, name-matching fallback, TLS options, and error mapping.    |
| `extensions/synology-chat/src/security.ts`                                      | Security helper(s).                                                                                           | Affects webhook/token and route safety surfaces.                                            |
| `extensions/synology-chat/src/test-http-utils.ts` / `src/channel.test-mocks.ts` | Test HTTP/mocking support.                                                                                    | Shared by webhook/channel integration tests.                                                |
| `extensions/synology-chat/src/*.test.ts`                                        | Colocated channel/client/core/webhook tests.                                                                  | First validation layer for this plugin.                                                     |

## Update rule

When a changed file maps to a row above, update `code-paths.md` and `change-to-test.md` with the runtime path and minimal validation command.
