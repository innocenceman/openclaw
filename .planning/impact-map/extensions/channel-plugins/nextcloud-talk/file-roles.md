# nextcloud-talk Channel Plugin File Roles

Coverage: `deep-partial`
Freshness: 2026-05-07 repo-native structural inspection only

| File or path                                                           | Role                                                                                                            | Impact notes                                                                                             |
| ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `extensions/nextcloud-talk/openclaw.plugin.json`                       | Plugin manifest for id/channel registration.                                                                    | Affects channel catalog, bundled plugin invariants, and setup/docs discovery.                            |
| `extensions/nextcloud-talk/package.json`                               | Package metadata, exports, install docs, and runtime deps.                                                      | Affects install-on-demand behavior and plugin package compatibility.                                     |
| `extensions/nextcloud-talk/index.ts` / `setup-entry.ts`                | Plugin and setup entrypoints.                                                                                   | Affects loader registration, setup entry discovery, and runtime setter wiring.                           |
| `extensions/nextcloud-talk/api.ts` / `runtime-api.ts`                  | Local/API barrels.                                                                                              | Keep plugin imports on public SDK or local barrel surfaces.                                              |
| `extensions/nextcloud-talk/src/channel.ts`                             | Main channel adapter: metadata, config/status, gateway monitor, logout, pairing, messaging, outbound delegates. | Central impact point for all Nextcloud Talk behavior paths.                                              |
| `extensions/nextcloud-talk/src/accounts.ts`                            | Scoped account enumeration/default/account resolution.                                                          | Affects multi-account config, account selection, status, setup, send, and monitor.                       |
| `extensions/nextcloud-talk/src/config-schema.ts` / `src/types.ts`      | Zod schema and typed config/payload contracts.                                                                  | Affects validation, compatibility, open allowFrom requirements, webhook payload typing, and room config. |
| `extensions/nextcloud-talk/src/setup-core.ts` / `src/setup-surface.ts` | Setup adapter/wizard, base URL normalization, bot/API credentials, DM/group policy prompts.                     | Affects onboarding, status, account fields, docs links, and optional room lookup.                        |
| `extensions/nextcloud-talk/src/secret-input.ts`                        | Secret input/file/env normalization.                                                                            | Affects bot and API secret compatibility.                                                                |
| `extensions/nextcloud-talk/src/monitor.ts`                             | Webhook server/handler, account status, replay/signature checks, inbound dispatch.                              | Affects gateway route, webhook security, lifecycle, and status reporting.                                |
| `extensions/nextcloud-talk/src/signature.ts`                           | Nextcloud Talk signature generation/verification.                                                               | Affects inbound webhook auth and outbound bot request auth.                                              |
| `extensions/nextcloud-talk/src/replay-guard.ts`                        | Replay protection.                                                                                              | Affects duplicate/replay rejection and webhook security windows.                                         |
| `extensions/nextcloud-talk/src/inbound.ts`                             | Webhook payload parsing and inbound message context.                                                            | Affects sender/room/message extraction, body normalization, and routing context.                         |
| `extensions/nextcloud-talk/src/policy.ts`                              | DM/group/room policy and tool policy resolution.                                                                | Affects authorization, mention requirements, route allowlists, and room-specific tool behavior.          |
| `extensions/nextcloud-talk/src/room-info.ts`                           | Optional API lookup for room metadata.                                                                          | Affects room name/DM detection and setup/monitor context when API credentials exist.                     |
| `extensions/nextcloud-talk/src/normalize.ts` / `src/format.ts`         | Target normalization and message formatting helpers.                                                            | Affects send target syntax, session route, and rendered reply text.                                      |
| `extensions/nextcloud-talk/src/session-route.ts`                       | Outbound session route mapping for room tokens.                                                                 | Affects manual send/session threading context.                                                           |
| `extensions/nextcloud-talk/src/send.ts`                                | OCS bot message/reaction send, Markdown conversion, error mapping.                                              | Affects outbound messages, reactions, room token requirements, and auth signature payloads.              |
| `extensions/nextcloud-talk/src/runtime.ts`                             | Runtime injection getter/setter.                                                                                | Affects tests and plugin runtime access.                                                                 |
| `extensions/nextcloud-talk/src/monitor.test-*.ts`                      | Monitor fixtures/harness.                                                                                       | Shared test support for inbound/replay behavior.                                                         |
| `extensions/nextcloud-talk/src/*.test.ts`                              | Colocated setup/core/inbound/monitor tests.                                                                     | First validation layer for this plugin.                                                                  |

## Update rule

When a changed file maps to a row above, update `code-paths.md` and `change-to-test.md` with the traced runtime path and narrowest validation command.
