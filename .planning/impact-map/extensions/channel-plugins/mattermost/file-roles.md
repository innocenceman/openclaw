# mattermost Channel Plugin File Roles

Coverage: `deep-partial`
Freshness: 2026-05-07 repo-native structural inspection only

| File or path                                                                              | Role                                                                                    | Impact notes                                                                                              |
| ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `extensions/mattermost/openclaw.plugin.json`                                              | Plugin manifest for id/channel registration.                                            | Affects plugin catalog, bundled plugin invariants, setup lists, and docs link routing.                    |
| `extensions/mattermost/package.json`                                                      | Package metadata, install spec, exports, scripts, and runtime dependencies.             | Affects workspace installs, bundled runtime dependency staging, and plugin SDK import contracts.          |
| `extensions/mattermost/index.ts`                                                          | Plugin entrypoint; registers channel behavior and late-bound slash-command route state. | Changes can affect loader registration, channel availability, slash route exposure, and runtime teardown. |
| `extensions/mattermost/api.ts` / `extensions/mattermost/runtime-api.ts`                   | Public/local API barrels.                                                               | Keep extension production imports inside package/API boundaries; changes can affect SDK consumers.        |
| `extensions/mattermost/src/channel.ts`                                                    | Main channel adapter composition: setup, status/probe, send, monitor, actions.          | Central impact point for every Mattermost behavior path.                                                  |
| `extensions/mattermost/src/setup-core.ts` / `src/setup-surface.ts` / `src/setup-entry.ts` | Interactive/non-interactive setup and user-facing status/config issue surface.          | Affects setup UX, account config, docs sync, and app provider settings.                                   |
| `extensions/mattermost/src/mattermost/accounts.ts`                                        | Account resolution, reply-to mode, and enabled-account enumeration.                     | Affects multi-account behavior, default target resolution, and monitor/send account selection.            |
| `extensions/mattermost/src/mattermost/client.ts`                                          | Mattermost REST client and retry/error handling.                                        | Affects send, directory, reactions, slash registration, probe, and resource fetches.                      |
| `extensions/mattermost/src/mattermost/directory.ts`                                       | Directory peers/groups listing.                                                         | Affects target selection and user/channel discovery.                                                      |
| `extensions/mattermost/src/mattermost/interactions.ts`                                    | Interactive callback URL/secret/token handling and button attachments.                  | Affects action security, model picker interactions, and reply button payloads.                            |
| `extensions/mattermost/src/mattermost/model-picker.ts`                                    | Model picker UI/context for Mattermost messages.                                        | Affects native interaction UX and model selection propagation.                                            |
| `extensions/mattermost/src/mattermost/monitor-auth.ts`                                    | Allowlist normalization and command authorization.                                      | Affects inbound command gating and sender trust boundaries.                                               |
| `extensions/mattermost/src/mattermost/monitor-gating.ts`                                  | Channel type/chat type and mention gating.                                              | Affects when inbound posts are routed to OpenClaw.                                                        |
| `extensions/mattermost/src/mattermost/monitor-resources.ts`                               | Media resource cache/fetch/save helpers.                                                | Affects inbound attachments and remote-resource safety.                                                   |
| `extensions/mattermost/src/mattermost/monitor-slash.ts`                                   | Monitor-time slash command registration and callback URL derivation.                    | Affects command lifecycle, callback URLs, and team-scoped route state.                                    |
| `extensions/mattermost/src/mattermost/monitor-websocket.ts`                               | Websocket event parsing and connect-once runtime.                                       | Affects inbound post delivery, reconnect behavior, and event payload shape.                               |
| `extensions/mattermost/src/mattermost/monitor.ts`                                         | Monitor provider, dedupe, thread/root context, websocket URL, and dispatch.             | Main inbound behavior path; changes can affect routing, threading, authorization, and media.              |
| `extensions/mattermost/src/mattermost/reactions.ts`                                       | Reaction add/remove behavior and bot user cache.                                        | Affects action execution and UX feedback.                                                                 |
| `extensions/mattermost/src/mattermost/reply-delivery.ts`                                  | Reply payload delivery.                                                                 | Affects auto-reply and threaded response delivery semantics.                                              |
| `extensions/mattermost/src/mattermost/send.ts`                                            | Outbound send, reply buttons, result mapping.                                           | Affects message creation, target addressing, threading, and button attachments.                           |
| `extensions/mattermost/src/mattermost/slash-commands.ts` / `slash-state.ts`               | Slash command registration, cleanup, parsing, and route state.                          | Affects HTTP command route behavior and installation cleanup.                                             |
| `extensions/mattermost/src/mattermost/target-resolution.ts`                               | Explicit target parsing and opaque target cache.                                        | Affects CLI/manual send target routing and thread-bound outbound behavior.                                |
| `extensions/mattermost/src/normalize.ts` / `src/group-mentions.ts`                        | Text normalization and group mention behavior.                                          | Affects inbound parsing, policy matching, and outgoing mention rendering.                                 |
| `extensions/mattermost/src/session-route.ts`                                              | Session route integration.                                                              | Affects web/session handoff and route exposure.                                                           |
| `extensions/mattermost/src/**/*.test.ts`                                                  | Colocated contract, unit, and behavior tests.                                           | Use as the first validation layer before broader channel/plugin gates.                                    |

## Update rule

When a change touches a row above, update `code-paths.md` with the traced runtime path and `change-to-test.md` with the narrowest proof command before relying on this map for regression selection.
