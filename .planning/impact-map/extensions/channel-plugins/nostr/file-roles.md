# nostr Channel Plugin File Roles

Coverage: `deep-partial`
Freshness: 2026-05-07 repo-native structural inspection only

| File or path                                              | Role                                                                                                                     | Impact notes                                                                                                    |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| `extensions/nostr/openclaw.plugin.json`                   | Plugin manifest for id/channel registration.                                                                             | Affects channel catalog, bundled plugin invariants, and docs/setup discovery.                                   |
| `extensions/nostr/package.json`                           | Package metadata, `nostr-tools` runtime dependency, install docs, exports.                                               | Affects install-on-demand, runtime dependency staging, and published plugin compatibility.                      |
| `extensions/nostr/index.ts`                               | Plugin entrypoint plus `/api/channels/nostr` profile HTTP route registration.                                            | Affects loader registration, gateway route exposure, profile config read/write, and account info lookup.        |
| `extensions/nostr/setup-entry.ts` / `setup-api.ts`        | Setup entry/API support.                                                                                                 | Affects setup plugin discovery and setup integration.                                                           |
| `extensions/nostr/api.ts` / `runtime-api.ts`              | Runtime/API barrels.                                                                                                     | Keep imports on local/public SDK surfaces.                                                                      |
| `extensions/nostr/src/channel.ts`                         | Main channel adapter: config/status, pairing, gateway bus lifecycle, inbound access, outbound send, profile publication. | Central impact point for Nostr behavior and active bus state.                                                   |
| `extensions/nostr/src/config-schema.ts`                   | Nostr config/profile schemas and safe HTTPS URL validation.                                                              | Affects config compatibility, profile metadata, SSRF-sensitive URL acceptance, and UI schema.                   |
| `extensions/nostr/src/setup-surface.ts`                   | Setup adapter/wizard, private key validation, relay URL parsing, allowFrom prompts, DM policy.                           | Affects onboarding, env key support, relay config, and allowlist normalization.                                 |
| `extensions/nostr/src/types.ts`                           | Account resolution/default account and config typing.                                                                    | Affects account status, bus startup, profile route, and send config.                                            |
| `extensions/nostr/src/default-relays.ts`                  | Default relay set.                                                                                                       | Affects connectivity and operator default behavior.                                                             |
| `extensions/nostr/src/runtime.ts`                         | Runtime injection getter/setter.                                                                                         | Affects tests and plugin runtime access.                                                                        |
| `extensions/nostr/src/nostr-bus.ts`                       | Relay connection, event validation, NIP-04 encryption/decryption, send/subscribe, inbound callback.                      | Affects all inbound/outbound DM behavior, relay resiliency, duplicate filtering, and cryptographic correctness. |
| `extensions/nostr/src/seen-tracker.ts`                    | Seen-event LRU/TTL tracking.                                                                                             | Affects duplicate suppression and memory bounds.                                                                |
| `extensions/nostr/src/metrics.ts`                         | Metrics event collection/snapshot.                                                                                       | Affects status health and relay/decrypt observability.                                                          |
| `extensions/nostr/src/nostr-state-store.ts`               | Persistent Nostr state store.                                                                                            | Affects profile/bus state and filesystem persistence.                                                           |
| `extensions/nostr/src/session-route.ts`                   | Outbound DM session route mapping.                                                                                       | Affects manual sends and session peer classification for Nostr pubkeys.                                         |
| `extensions/nostr/src/nostr-profile.ts`                   | NIP-01 profile publish/build/validate helpers.                                                                           | Affects profile metadata publication and relay events.                                                          |
| `extensions/nostr/src/nostr-profile-import.ts`            | Profile import/merge/sanitize from relays.                                                                               | Affects profile compatibility, relay reads, signature validation, and URL sanitization.                         |
| `extensions/nostr/src/nostr-profile-http.ts`              | Gateway HTTP handler for profile view/update/import.                                                                     | Affects control UI route, auth-scoped profile updates, and account metadata.                                    |
| `extensions/nostr/test/setup.ts` / `src/test-fixtures.ts` | Test support fixtures.                                                                                                   | Shared by Nostr colocated tests.                                                                                |
| `extensions/nostr/src/*.test.ts`                          | Colocated channel, bus, profile, store, fuzz, and integration tests.                                                     | First validation layer for this plugin.                                                                         |
