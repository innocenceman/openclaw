# WhatsApp Channel Plugin File Roles

Coverage: `deep-partial`
Freshness: 2026-05-07 repo-native structural inspection only

## Package and registration

| File or path                               | Role                                                                                                                                      | Impact notes                                                                                                            |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `extensions/whatsapp/openclaw.plugin.json` | Declares plugin id `whatsapp`, channel id `whatsapp`, and empty plugin config schema.                                                     | Catalog, install, setup/status, docs, and invariant tests can break if id/schema changes.                               |
| `extensions/whatsapp/package.json`         | Workspace package metadata for `@openclaw/whatsapp`, Baileys/Jimp runtime deps, peer host version, install metadata, channel labels/docs. | Affects plugin staging/install, dependency bundling, npm publish expectations, channel picker metadata, and docs links. |
| `extensions/whatsapp/index.ts`             | Plugin entrypoint using `defineChannelPluginEntry`, `whatsappPlugin`, and `setWhatsAppRuntime`.                                           | Loader boundary; changes affect whether the channel registers and whether runtime injection reaches the plugin.         |
| `extensions/whatsapp/api.ts`               | Root public API barrel for extension consumers.                                                                                           | Public import surface; changes can affect tests or other packages that use WhatsApp helpers.                            |
| `extensions/whatsapp/runtime-api.ts`       | Root runtime API barrel.                                                                                                                  | Public/runtime import surface; keep aligned with source-local barrels.                                                  |
| `extensions/whatsapp/src/runtime-api.ts`   | Source-local barrel for WhatsApp core/shared helpers, normalizers, target resolution, and monitor export.                                 | Internal extension import seam; changes can ripple across plugin files and external SDK-style imports.                  |
| `extensions/whatsapp/src/runtime.ts`       | Stores the plugin runtime provided by the host through `setWhatsAppRuntime`.                                                              | Any missing runtime method can break chunking, senders, config/status adapters, setup, or pairing helpers.              |

## Channel composition and config/status

| File or path                               | Role                                                                                                                                                                                     | Impact notes                                                                                                                         |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `extensions/whatsapp/src/channel.ts`       | Main `whatsappPlugin` composition: outbound adapter, setup wizard, config checks, login/logout, status, allowlist, directory, action/poll support, heartbeat, and gateway monitor start. | Highest fan-out file. Before changing, trace setup/login/status/inbound/outbound paths and run the broadest targeted WhatsApp tests. |
| `extensions/whatsapp/src/config-schema.ts` | Builds `WhatsAppChannelConfigSchema` from plugin SDK WhatsApp schema.                                                                                                                    | Config validation and generated schema/docs drift can occur if this changes.                                                         |
| `extensions/whatsapp/src/setup-surface.ts` | Merges config, prompts DM/owner/self-chat policies, checks stored auth, and optionally starts QR login in setup.                                                                         | User-facing onboarding and config mutation surface; changes require setup/status tests and docs review if copy/behavior changes.     |
| `extensions/whatsapp/src/status-issues.ts` | Converts link/running/reconnect/health state into status issues.                                                                                                                         | Affects `channels status`, UI health indicators, and troubleshooting guidance.                                                       |
| `extensions/whatsapp/src/group-policy.ts`  | Resolves WhatsApp group mention/tool policies through shared channel helpers.                                                                                                            | Affects group routing, command/tool gating, and reply behavior in groups.                                                            |
| `extensions/whatsapp/src/prompt.ts`        | WhatsApp-specific prompt text or prompt helpers.                                                                                                                                         | Affects agent behavior/context; test via inbound context or prompt-specific tests when touched.                                      |
| `extensions/whatsapp/src/types.ts`         | Shared WhatsApp plugin types.                                                                                                                                                            | Type-only changes can still alter public contracts if exported through barrels.                                                      |

## Auth, account, session, and reconnect lifecycle

| File or path                                 | Role                                                                                                        | Impact notes                                                                                                        |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `extensions/whatsapp/src/accounts.ts`        | Resolves account ids, auth dirs, per-account config overlays, media caps, and legacy/default auth location. | Affects multi-account behavior, login, status, send, and monitor config overlays.                                   |
| `extensions/whatsapp/src/auth-store.ts`      | Auth dir/creds paths, backup restore, credential existence, logout cleanup, self identity reads, auth age.  | High-risk persistence boundary; can log users out or hide linked status if wrong.                                   |
| `extensions/whatsapp/src/login.ts`           | QR login flow, socket creation, connection wait, Baileys status handling, 515 restart/retry handling.       | Affects setup/login UX and credential persistence; validate login and QR tests.                                     |
| `extensions/whatsapp/src/session.ts`         | Baileys socket creation, connection wait, credential save queue wait, error/status helpers, connection id.  | Core transport boundary; changes affect login, monitor, sends, and reconnect handling.                              |
| `extensions/whatsapp/src/reconnect.ts`       | Heartbeat interval resolution, reconnect policy, backoff, abortable sleep, connection id.                   | Affects gateway stability and retry behavior; validate reconnect and heartbeat tests.                               |
| `extensions/whatsapp/src/active-listener.ts` | Global active listener registry by account/default and `requireActiveWebListener` error path.               | Outbound sends/polls/reactions depend on this; multi-account or gateway lifecycle changes need send/listener tests. |

## Inbound monitor and message normalization

| File or path                                        | Role                                                                                                                                                     | Impact notes                                                                               |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `extensions/whatsapp/src/inbound/monitor.ts`        | Baileys inbox listener: self identity, dedupe, group metadata cache, access control, read receipts, media extraction, reply/send API, connection events. | Core inbound path; changes can affect routing, privacy, group behavior, media, and status. |
| `extensions/whatsapp/src/inbound/access-control.ts` | DM/group/self-chat policies, allowlists, pairing challenges, and command/user authorization.                                                             | Security/authorization-sensitive. Validate allow/deny/pairing and command-gate behavior.   |
| `extensions/whatsapp/src/inbound/extract.ts`        | Unwraps Baileys wrappers and extracts text, location, mentions, reply context, and vCards.                                                               | Affects what the agent sees and whether replies/context/media are recognized.              |
| `extensions/whatsapp/src/inbound/media.ts`          | Downloads inbound media and builds saved media metadata.                                                                                                 | Affects attachment handling, file paths, media URLs, and size limits.                      |
| `extensions/whatsapp/src/inbound/types.ts`          | `WebInboundMessage` contract consumed by auto-reply and tests.                                                                                           | Contract changes must be reflected in auto-reply context and tests.                        |

## Auto-reply, routing, and delivery

| `extensions/whatsapp/src/auto-reply/monitor/group-history.ts`   | Group history context helper.                                                                                                                                                   | Affects group context quality and prompt size/ordering.                                                                   |
| `extensions/whatsapp/src/auto-reply/monitor/group-members.ts`   | Group member formatting/lookup helpers.                                                                                                                                         | Affects inbound context and mention/member metadata.                                                                      |
| `extensions/whatsapp/src/auto-reply/monitor/outbound-echo.ts`   | Tracks recent outbound group sends to suppress self echo.                                                                                                                       | Affects duplicate replies and group echo suppression.                                                                     |
| `extensions/whatsapp/src/auto-reply/monitor/reactions.ts`       | ACK/reaction helper behavior.                                                                                                                                                   | Affects message acknowledgment side effects.                                                                              |
| `extensions/whatsapp/src/auto-reply/monitor/types.ts`           | Auto-reply monitor type contracts.                                                                                                                                              | Type changes ripple across monitor/process-message tests.                                                                 |
| `extensions/whatsapp/src/auto-reply/monitor/utils.ts`           | Shared monitor utilities.                                                                                                                                                       | Re-run monitor utility tests when touched.                                                                                |

## Outbound, send, polls, reactions, and media

| File or path                                         | Role                                                                                                                                                           | Impact notes                                                                                              |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `extensions/whatsapp/src/outbound-adapter.ts`        | `ChannelOutboundAdapter`: target resolution, text chunk limit, poll cap, lazy send imports, final payload sending.                                             | Affects generic OpenClaw outbound-to-WhatsApp bridge and contract expectations.                           |
| `extensions/whatsapp/src/resolve-outbound-target.ts` | Resolves outbound targets into WhatsApp recipient form.                                                                                                        | Affects explicit target parsing, account routing, and direct/group sends.                                 |
| `extensions/whatsapp/src/resolve-target.ts`          | Converts numbers/JIDs/groups to Baileys targets.                                                                                                               | Affects send/listPeers/listGroups and user-facing target syntax.                                          |
| `extensions/whatsapp/src/session-route.ts`           | Builds outbound session route from normalized target/chat type/account.                                                                                        | Affects last-route/session routing and replies to chosen conversations.                                   |
| `extensions/whatsapp/src/send.ts`                    | Sends text/media/reactions/polls through active listener, handles markdown conversion, captions, audio opus, documents, composing indicators, and message ids. | Core outbound side-effect boundary. Validate send, poll, reaction, media, and listener tests after edits. |
| `extensions/whatsapp/src/media.ts`                   | Loads remote/local outbound media with SSRF/local-root guards, MIME detection, image optimization, HEIC conversion, and size caps.                             | Security-sensitive. Changes require media tests and possibly broader security review.                     |
| `extensions/whatsapp/src/poll.ts`                    | Poll helper/types if touched.                                                                                                                                  | Validate poll adapter and send poll tests.                                                                |
| `extensions/whatsapp/src/markdown.ts`                | WhatsApp markdown/table conversion.                                                                                                                            | Validate send formatting tests and any table rendering behavior.                                          |
| `extensions/whatsapp/src/jid.ts`                     | WhatsApp JID helpers.                                                                                                                                          | Affects target normalization, sender identity, group/direct inference.                                    |
| `extensions/whatsapp/src/normalize.ts`               | Normalization helpers.                                                                                                                                         | Affects inbound/outbound target and payload consistency.                                                  |
