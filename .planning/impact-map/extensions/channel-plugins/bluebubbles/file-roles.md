## Webhook inbound, normalization, and reply pipeline

| File or path                                            | Role                                                                                                                                                                   | Impact notes                                                  |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| `extensions/bluebubbles/src/monitor.ts`                 | Webhook target registry, in-flight limiter, auth token comparison, request body parsing, event filter, message/reaction dispatch.                                      | External HTTP surface; auth/body/event changes are high risk. |
| `extensions/bluebubbles/src/webhook-shared.ts`          | Shared webhook constants/types.                                                                                                                                        | Setup docs and webhook route consistency.                     |
| `extensions/bluebubbles/src/monitor-normalize.ts`       | Normalizes webhook message/reaction payloads, tapbacks, placeholders, group members, reply tags.                                                                       | Affects what enters the agent prompt and reactions.           |
| `extensions/bluebubbles/src/monitor-debounce.ts`        | Debounces/coalesces rapid webhook message events.                                                                                                                      | Affects duplicate/fragmented inbound messages.                |
| `extensions/bluebubbles/src/monitor-processing.ts`      | Core inbound path: self-chat/fromMe handling, access/pairing, command/mention gating, route/session context, history, reply pipeline, outbound id tracking, reactions. | Routing/security/reply-critical.                              |
| `extensions/bluebubbles/src/monitor-reply-cache.ts`     | Maps BlueBubbles GUIDs to short ids and reply context.                                                                                                                 | Affects reply threading and displayed message ids.            |
| `extensions/bluebubbles/src/monitor-self-chat-cache.ts` | Reflection guard for self-chat duplicates.                                                                                                                             | Prevents duplicate assistant replies.                         |
| `extensions/bluebubbles/src/history.ts`                 | Fetches/prunes message history for context backfill.                                                                                                                   | Affects group/DM context and prompt size.                     |
| `extensions/bluebubbles/src/monitor-shared.ts`          | Monitor target/runtime types.                                                                                                                                          | Contract across monitor and processing.                       |
