# zalo Channel Plugin File Roles

Coverage: `deep-partial`
Freshness: 2026-05-07 repo-native structural inspection only

| File or path                                                       | Role                                                                                                                                             | Impact notes                                                                                          |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| `extensions/zalo/openclaw.plugin.json`                             | Plugin manifest for id/channel registration.                                                                                                     | Affects channel catalog, bundled plugin invariants, and setup/docs discovery.                         |
| `extensions/zalo/package.json`                                     | Package metadata, install docs, undici/zod runtime deps.                                                                                         | Affects install-on-demand and published plugin compatibility.                                         |
| `extensions/zalo/index.ts` / `setup-entry.ts`                      | Plugin/setup entrypoints.                                                                                                                        | Affects loader registration, setup discovery, and runtime setter wiring.                              |
| `extensions/zalo/api.ts` / `runtime-api.ts` / `src/runtime-api.ts` | Setup/runtime barrels.                                                                                                                           | Affects setup consumers and local SDK-facing imports.                                                 |
| `extensions/zalo/src/channel.ts`                                   | Main channel adapter: config/status/probe, directory, DM/group security, actions, messaging target/session, gateway monitor, outbound delegates. | Central impact point for Zalo behavior.                                                               |
| `extensions/zalo/src/channel.runtime.ts` / `src/runtime.ts`        | Lazy runtime implementation and runtime injection.                                                                                               | Affects probe/send/monitor runtime loading and build boundaries.                                      |
| `extensions/zalo/src/accounts.ts`                                  | Scoped account resolution, default account, enabled state, token source.                                                                         | Affects setup, status, probe, send, monitor, and multi-account routing.                               |
| `extensions/zalo/src/config-schema.ts` / `src/types.ts`            | Multi-account config schema and typed payload/account contracts.                                                                                 | Affects bot token/tokenFile, webhook mode, DM/group policy, proxy, media limits, and response prefix. |
| `extensions/zalo/src/secret-input.ts` / `src/token.ts`             | Secret input/file/env token resolution.                                                                                                          | Affects token compatibility and setup/status source reporting.                                        |
| `extensions/zalo/src/setup-core.ts` / `src/setup-surface.ts`       | Setup adapter/wizard, token prompts, webhook mode/path/secret, numeric allowFrom prompt.                                                         | Affects onboarding, polling vs webhook mode, secret UX, account config, and docs hints.               |
| `extensions/zalo/src/status-issues.ts`                             | Status issue collection.                                                                                                                         | Affects operator diagnostics for missing tokens/webhook config.                                       |
| `extensions/zalo/src/probe.ts`                                     | Account probe.                                                                                                                                   | Affects status health checks and API reachability.                                                    |
| `extensions/zalo/src/proxy.ts`                                     | Proxy-aware fetch resolver.                                                                                                                      | Affects API/send/probe network behavior and proxy caching.                                            |
| `extensions/zalo/src/api.ts`                                       | Zalo Bot API primitives.                                                                                                                         | Affects message send/photo send, polling/webhook API calls, and response/error parsing.               |
| `extensions/zalo/src/send.ts`                                      | Text/photo send wrapper and media handling.                                                                                                      | Affects outbound/manual/action sends, media URL handling, chunking, and error mapping.                |
| `extensions/zalo/src/actions.ts` / `actions.runtime.ts`            | Message action adapter and lazy runtime.                                                                                                         | Affects action discovery and tool `send` behavior.                                                    |
| `extensions/zalo/src/monitor.ts`                                   | Polling/webhook monitor orchestration.                                                                                                           | Affects inbound lifecycle, image polling, pairing, group policy, and reply dispatch.                  |
| `extensions/zalo/src/monitor.webhook.ts`                           | Webhook HTTP route/secret handling.                                                                                                              | Affects webhook verification, replay/duplicate behavior, and inbound route security.                  |
| `extensions/zalo/src/group-access.ts`                              | Group access helpers.                                                                                                                            | Affects groupPolicy/groupAllowFrom and mention-gated group behavior.                                  |
| `extensions/zalo/src/session-route.ts`                             | Outbound session route mapping.                                                                                                                  | Affects direct/group session keys and manual send context.                                            |
| `extensions/zalo/src/**/*.test.ts`                                 | Colocated account/API/channel/config/monitor/send/setup/status/token tests.                                                                      | First validation layer for this plugin.                                                               |

## Update rule

When a changed file maps to a row above, update `code-paths.md` and `change-to-test.md` with the runtime path and minimal validation command.
