# signal Channel Plugin File Roles

Coverage: `deep-partial`
Freshness: 2026-05-07 repo-native structural inspection only

| File or path                                                                                   | Role                                                                                                           | Impact notes                                                                                             |
| ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `extensions/signal/openclaw.plugin.json`                                                       | Plugin manifest for id/channel registration.                                                                   | Affects channel catalog and bundled plugin invariants.                                                   |
| `extensions/signal/package.json`                                                               | Private bundled plugin metadata and setup entry metadata.                                                      | Affects plugin discovery and package boundary checks.                                                    |
| `extensions/signal/index.ts` / `setup-entry.ts`                                                | Channel and setup entrypoints.                                                                                 | Affects loader registration, setup discovery, and runtime setter wiring.                                 |
| `extensions/signal/api.ts` / `runtime-api.ts` / `src/runtime-api.ts`                           | Signal API/runtime barrels.                                                                                    | Affects imports by core/tests and plugin SDK-facing surfaces.                                            |
| `extensions/signal/src/channel.ts`                                                             | Main channel adapter: outbound delegates, formatting, actions, config/status, messaging target/session routes. | Central impact point for Signal behavior.                                                                |
| `extensions/signal/src/channel.runtime.ts`                                                     | Lazy runtime implementation boundary.                                                                          | Affects dynamic runtime loading and build boundary behavior.                                             |
| `extensions/signal/src/channel.setup.ts`                                                       | Setup plugin composition.                                                                                      | Affects setup-only registration and setup wizard exposure.                                               |
| `extensions/signal/src/shared.ts` / `src/plugin-shared.ts`                                     | Shared plugin base/config/security setup used by channel/setup.                                                | Affects config adapter, security adapter, and duplicated setup/channel behavior.                         |
| `extensions/signal/src/accounts.ts`                                                            | Account resolution and default account handling.                                                               | Affects multi-account routing, setup, status, send, monitor, and media limits.                           |
| `extensions/signal/src/config-schema.ts`                                                       | Config schema wrapper.                                                                                         | Affects config validation and UI schema.                                                                 |
| `extensions/signal/src/setup-core.ts` / `src/setup-surface.ts`                                 | signal-cli path/number setup, binary detection/install prompt, allowFrom parsing, DM policy.                   | Affects onboarding, local binary requirements, linked account config, and docs/status hints.             |
| `extensions/signal/src/client.ts`                                                              | Signal REST/RPC/SSE client.                                                                                    | Affects probe, monitor, send, receipts, reactions, and error handling.                                   |
| `extensions/signal/src/rpc-context.ts`                                                         | Resolves account/base URL for RPC requests.                                                                    | Affects every runtime call needing account/baseUrl context.                                              |
| `extensions/signal/src/probe.ts`                                                               | Signal service health/version checks.                                                                          | Affects channel status and diagnostics.                                                                  |
| `extensions/signal/src/daemon.ts` / `src/sse-reconnect.ts`                                     | Optional daemon autostart and SSE reconnect loop.                                                              | Affects monitor lifecycle, background process handling, and reconnection policy.                         |
| `extensions/signal/src/monitor.ts`                                                             | Signal monitor provider; connects to SSE/RPC, starts daemon if configured, dispatches inbound events.          | Main inbound lifecycle and runtime resource boundary.                                                    |
| `extensions/signal/src/monitor/access-policy.ts`                                               | Sender/group access policy.                                                                                    | Affects allowlists, group policy, pairing, and UUID sender matching.                                     |
| `extensions/signal/src/monitor/event-handler.ts` / `event-handler.types.ts`                    | Inbound message/event handling and reply dispatch.                                                             | Affects inbound context, mentions, command/tool result behavior, receipts, reactions, and route updates. |
| `extensions/signal/src/monitor/mentions.ts`                                                    | Signal mention detection/gating helpers.                                                                       | Affects group mention requirements and inbound routing.                                                  |
| `extensions/signal/src/format.ts`                                                              | Markdown-to-Signal text/chunk styling.                                                                         | Affects outbound and auto-reply text rendering.                                                          |
| `extensions/signal/src/send.ts`                                                                | Signal text/media send.                                                                                        | Affects REST payloads, attachment/media handling, and send result mapping.                               |
| `extensions/signal/src/send-reactions.ts` / `src/reaction-level.ts` / `src/message-actions.ts` | Reaction send behavior and message action metadata.                                                            | Affects thumbs/reaction action execution and UI/tool capability exposure.                                |
| `extensions/signal/src/identity.ts`                                                            | Identity helpers.                                                                                              | Affects sender/account identity display and pairing hints.                                               |
| `extensions/signal/src/**/*.test.ts`                                                           | Colocated client/core/monitor/outbound/format/reaction tests.                                                  | First validation layer for Signal changes.                                                               |

## Update rule

When a changed file maps to a row above, update `code-paths.md` and `change-to-test.md` with the runtime path and minimal validation command.
