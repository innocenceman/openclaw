Freshness: 2026-05-08 repo-native structural inspection only

| File or path                                                                                                     | Role                                                                                                               | Impact notes                                                                          |
| ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| `extensions/openai/openclaw.plugin.json`, `package.json`, `index.ts`                                             | Manifest/package/entry contract for provider ids, auth choices, and multi-surface registration.                    | Catalog, onboarding, package/install, and loader behavior.                            |

| `extensions/openai/image-generation-provider.ts`                                                                 | Image generation HTTP path, base-url resolution, timeout handling, and base64 image decoding.                      | Image output, auth, and provider-specific API compatibility.                          |
| `extensions/openai/media-understanding-provider.ts`, `speech-provider.ts`                                        | Media-understanding and TTS/telephony plugin surfaces.                                                             | Audio/image capability registration and runtime auth/config usage.                    |
| `extensions/openai/shared.ts`                                                                                    | Shared provider helper functions for template lookup and base-url matching.                                        | Used by both direct OpenAI and Codex provider code paths.                             |
| `extensions/openai/index.test.ts`, `openai-provider.test.ts`, `openai-codex-auth-identity.test.ts`               | Nearest local regression anchors for registration, provider runtime, and Codex identity behavior.                  | First stop before widening to shared command/model tests.                             |
