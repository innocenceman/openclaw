## Package, entry, and public barrels

| File or path                                                                    | Role                                                                                                                          | Impact notes                                                                                         |
| ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `extensions/telegram/openclaw.plugin.json`                                      | Declares plugin id `telegram`, channel id `telegram`, and plugin config schema.                                               | Channel catalog, setup/status, invariants, docs, and picker surfaces can break if id/schema changes. |
| `extensions/telegram/package.json`                                              | Package metadata for `@openclaw/telegram`, grammY runtime deps, setup entry, channel labels/docs, runtime dependency staging. | Affects plugin install/staging, docs links, picker labels, and runtime dependency packaging.         |
| `extensions/telegram/index.ts`                                                  | Plugin entrypoint using `defineChannelPluginEntry`, `telegramPlugin`, and `setTelegramRuntime`.                               | Loader boundary; changes affect plugin registration and runtime injection.                           |
| `extensions/telegram/api.ts`                                                    | Public root API barrel for Telegram helpers such as accounts, targets, outbound adapter, status issues, update offsets.       | Public extension surface; changes may affect imports outside the plugin.                             |
| `extensions/telegram/runtime-api.ts`                                            | Runtime-facing barrel for plugin SDK Telegram types/helpers and local monitor/send/probe/thread-binding exports.              | High-risk export surface; changes can affect runtime wiring and plugin SDK compatibility.            |
| `extensions/telegram/setup-entry.ts`                                            | Setup command entrypoint.                                                                                                     | Affects setup invocation from install/onboarding flows.                                              |
| `extensions/telegram/allow-from.ts` and `extensions/telegram/src/allow-from.ts` | Allowlist normalization/export helpers.                                                                                       | Affects allowFrom editing and pairing/security surfaces.                                             |
