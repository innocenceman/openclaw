## Suggested escalation ladder

1. Run the one or two nearest `extensions/whatsapp/**` tests listed above.
2. If the change touches shared channel contracts, add the nearest `src/channels/plugins/**` contract tests.
3. If the change touches install/runtime dependencies or exported barrels, add packaging/build validation.
4. If the change touches media/security/access control, add a security-focused review before landing.
5. If live behavior must be proven, use mock-first tests before any live WhatsApp/Baileys check.
