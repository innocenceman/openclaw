# Package Runtime Dependencies File Roles

Coverage: `deep-partial`
Freshness: 2026-05-08 repo-native inspection only

| File or path                                                                    | Role                                                                                                                      | Impact notes                                                                                        |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `extensions/*/package.json`                                                     | Runtime/dev/peer/optional dependency declaration and package naming.                                                      | First file to inspect when production imports or install behavior change.                           |
| `extensions/*/index.ts`                                                         | Root production import site and plugin entrypoint.                                                                        | Provider/config-only plugins often have all production code here.                                   |
| `extensions/*/src/**`                                                           | Production import sites for channel/client/media/provider SDKs.                                                           | Check imports against runtime deps before packaging or install tests.                               |
| `extensions/memory-lancedb/lancedb-runtime.ts`                                  | Plugin-local runtime loader/installer for `@lancedb/lancedb` when bundled runtime deps are unavailable.                   | Highest-risk current example of plugin-owned runtime installation and state-dir staging behavior.   |
| `extensions/memory-lancedb/config.ts`                                           | Memory LanceDB config parsing, env resolution, embedding-model defaults, UI hints.                                        | Dependency/config drift here can break runtime initialization without touching the main entrypoint. |
| `scripts/stage-bundled-plugin-runtime-deps.mjs`                                 | Stages or validates bundled plugin runtime dependencies.                                                                  | Paired with `pnpm stage:bundled-plugin-runtime-deps` and release checks.                            |
| `scripts/stage-bundled-plugin-runtime.mjs`                                      | Stages bundled plugin runtime files.                                                                                      | Entry/build path changes can affect packaged runtime contents.                                      |
| `scripts/lib/bundled-plugin-build-entries.mjs`                                  | Determines bundled plugin build entries.                                                                                  | Affects build and package staging coverage for extension entrypoints.                               |
| `test/scripts/stage-bundled-plugin-runtime-deps.test.ts`                        | Regression tests for runtime dependency staging script.                                                                   | First targeted test for dependency staging behavior.                                                |
| `src/plugins/stage-bundled-plugin-runtime.test.ts`                              | Runtime staging behavior test.                                                                                            | Run when bundled plugin runtime packaging changes.                                                  |
| `src/plugins/bundled-runtime-deps.test.ts`                                      | Guards plugin-local runtime deps that must stay owned by extension packages.                                              | Important when a plugin such as `memory-lancedb` should keep deps out of root packaging.            |
| `test/plugin-npm-release.test.ts` and `test/openclaw-npm-release-check.test.ts` | Plugin npm release/package checks.                                                                                        | Use for release/package validation; publish remains explicit-approval only.                         |
| Root `package.json` scripts                                                     | Defines `test:extensions`, `test:contracts:*`, `stage:bundled-plugin-runtime-deps`, `release:plugins:npm:check`, `build`. | Command source for validation matrix.                                                               |
